## 已确认

- 采集器只使用 Python 标准库，默认 SQLite，不启动交易终端、不执行下单。
- `collector.provider.FileQuoteProvider` 可读取用户导出的 JSON/CSV，用于验证字段解析和统计算法；它明确标记为 `file-export-only`，不能当作实时行情源。
- 五分钟涨幅需要同一交易时段五分钟前的有效价格；午休不跨窗口。日报排序规则和缺失值处理位于 `collector/statistics.py`。
